# @openota/shared

Shared TypeScript contracts for OpenOTA — `Manifest`, `RuntimeManifest`, API envelopes, error codes, and runtime states used by every OpenOTA package (`@openota/sdk`, `@openota/cli`, and the OpenOTA server).

This package is an internal dependency of the OpenOTA toolchain. You generally don't need to install it directly — it's pulled in automatically by `@openota/sdk` and `@openota/cli`.

## Install

```sh
npm install @openota/shared
```
